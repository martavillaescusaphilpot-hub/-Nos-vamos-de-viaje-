# -Nos-vamos-de-viaje-
Este proyecto está destinado a 6º de Primaria y, en él, el alumnado realizará la organización de su viaje de fin de curso. Cada grupo tendrá un presupuesto previo y deberá elegir el destino a donde quiera viajar y organizar los siguientes aspectos: reservas de vuelo y de alojamiento, visitas a museos y monumentos y organización y gastos de comidas.
